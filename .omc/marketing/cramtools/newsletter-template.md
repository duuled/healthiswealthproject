## Example Issue 2: Zapier AI Automation

**Subject:** I automated 3 hours of weekly admin. Here's the exact Zap.

---

Hey [FIRST NAME], the best automation is the one you never have to think about again. This week: the exact workflow that eliminated my client onboarding admin.

---

**TOOL OF THE WEEK: Zapier**

Zapier is the connective tissue of the modern solopreneur's stack. It moves data between apps so you don't have to. Their AI features — specifically natural language Zap building and AI steps inside workflows — made it dramatically easier to set up in the past year.

The workflow (Client Onboarding Automation):
1. Trigger: New client added to your CRM (or a form submission in Typeform/Tally).
2. Action 1: Zapier creates a project folder in Google Drive with your template structure.
3. Action 2: Zapier sends a personalized welcome email with their project details.
4. Action 3: Zapier creates a Slack channel (or Notion page) for the project.
5. Action 4 (AI step): Zapier uses AI to draft the first client check-in message based on project details.

Time saved: 25–35 minutes per new client. If you onboard 4 clients/month, that's 2+ hours back.

Best for: Freelancers and solopreneurs with repeatable onboarding steps.

Pricing: Free tier covers 100 tasks/month. Starter at $29.99/month handles higher volume.

[Try Zapier Free →] [AFFILIATE_LINK]

---

**PROMPT OF THE WEEK**

Use this in ChatGPT or Claude to build your automation brief before setting up Zapier:

```
I want to automate the following manual process:

[DESCRIBE YOUR PROCESS — e.g., "When I get a new client inquiry via email, I manually create a folder, send a response, and add them to my spreadsheet."]

Break this into:
1. The trigger event
2. Each sequential action that needs to happen
3. Any conditional logic (e.g., "if they're a new client, do X; if returning, do Y")
4. The apps I need to connect: [LIST YOUR APPS]

Format this as a numbered automation blueprint I can use to set up Zapier.
```

What it does: Translates a messy manual process into a clear automation spec in 60 seconds.

What to change: Replace the bracketed section with your actual process description. The more specific you are, the more useful the output.

---

**WORKFLOW TIP**

Before building any automation, time yourself doing the task manually — once. Open a timer, do the full task, stop the timer. Write that number down. Now build the automation and calculate the monthly time savings (manual time x frequency/month). This turns "automation" from a vague productivity concept into a concrete ROI number. If a $30/month Zapier plan saves you 3 hours/month at a $50/hour rate, you're paying $30 to make $150. That's the math that justifies every tool upgrade.
